# langflow-simple-agent
Simple AI Agent built with Langflow, Gemini, Web Search and URL tools.

## Project Overview
This project demonstrates a simple AI agent built using Langflow's visual workflow interface.

## Objective
To create a conversational AI agent that accepts user queries and can use web search and URL-fetching tools to retrieve information.

## Technologies Used
- Langflow — visual workflow development
- Google Gemini — language model
- Web Search — web information retrieval
- URL component — webpage content fetching
- Chat Input and Chat Output — user interaction

## Workflow
1. Chat Input receives the user's query.
2. The Agent processes the query.
3. The configured Gemini model generates the response.
4. Web Search and URL tools can provide additional information when needed.
5. Chat Output displays the result.

## Example
**Query:** Who is Lionel Messi?

**Expected demonstration:** The agent returns a response about Lionel Messi's career and achievements.

## Project Files
- `langflow-simple-agent.json` — exported Langflow workflow.
- `workflow-overview.png` — workflow canvas screenshot.
- `successful-output.png` — example output screenshot.

## Setup
1. Import the exported workflow into Langflow.
2. Configure the required Gemini credentials.
3. Verify the web-search and URL tools.
4. Run the flow and test it with sample queries.
